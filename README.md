# CSE472 Lab 05 - HTTP, Fetch and Simple API Use

## Student Workshop Registration System

This project is developed for **CSE472: Web and Internet Programming Lab 05**.

The project demonstrates how to load data using the JavaScript Fetch API and display JSON data dynamically on a webpage.

## Features

- Load workshop information from a JSON file
- Use JavaScript `fetch()` to request data
- Use `async` and `await`
- Check HTTP response status `200`
- Convert JSON response using `response.json()`
- Display workshop information dynamically
- Load sample user data from a public API
- Test requests using the browser Network panel

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
- Fetch API
- JSONPlaceholder API
